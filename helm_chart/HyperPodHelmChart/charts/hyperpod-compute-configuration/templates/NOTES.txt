{{- if .Values.webhook.enable }}

The compute configuration admission webhook is installed (image {{ include "hyperpod-compute-configuration.webhookImage" . }}).
It handles RayJob, HyperPodPyTorchJob and InferenceEndpointConfig creates and
updates that carry the compute.configuration.sagemaker.amazonaws.com/name label, in every
namespace except kube-system:
- The mutating webhook fills in compute and never blocks a workload (failurePolicy Ignore).
- The validating webhook runs only in namespaces labelled
  {{ include "hyperpod-compute-configuration.enforcementLabel" . }}=enabled and rejects workloads
  it can't check (failurePolicy Fail).
- A ValidatingAdmissionPolicy rejects labelled objects of other kinds in every namespace except
  kube-system, unless a controller created them (they have an owner, or come from
  webhook.workloadControllers).
- A second ValidatingAdmissionPolicy requires every RayJob, HyperPodPyTorchJob and
  InferenceEndpointConfig in enforced namespaces to use a compute configuration, and accepts them
  only in API version v1 (in any namespace when they reference a compute configuration).
Enforcement covers RayJob, HyperPodPyTorchJob and InferenceEndpointConfig. Other kinds (such as
RayCluster, Kubeflow PyTorchJob or Pods) are admitted as usual.
The webhook can read compute configurations and namespaces (read-only ClusterRole).{{ if .Values.certManager.enable }}
Its TLS certificate is issued by cert-manager, which must be installed in the cluster.{{ end }}

To verify the webhook:

  kubectl -n {{ include "hyperpod-compute-configuration.namespaceName" . }} rollout status deployment/{{ include "hyperpod-compute-configuration.webhookName" . }}
  kubectl -n {{ include "hyperpod-compute-configuration.namespaceName" . }} get certificate {{ include "hyperpod-compute-configuration.webhookName" . }}-cert
  kubectl get mutatingwebhookconfiguration,validatingwebhookconfiguration {{ include "hyperpod-compute-configuration.webhookName" . }}
  kubectl -n {{ include "hyperpod-compute-configuration.namespaceName" . }} logs deployment/{{ include "hyperpod-compute-configuration.webhookName" . }} | grep "Webhook version"
{{- end }}
